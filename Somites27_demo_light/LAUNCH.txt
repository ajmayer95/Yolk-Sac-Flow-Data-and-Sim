Stage-27 yolk-sac mosaic — read-only viewer
===========================================

Contents of this folder:
  PerTileFlow/             Bundled viewer code (~680 KB).  Pure Python,
                           no compiler / Cython needed.  Installable
                           with a single `pip install ./PerTileFlow`.
  emb1/
    config.json            Relative paths to the data files below.
    analyzed/
      mosaic_graph_analyzed.gpickle   Mosaic graph with per-edge measurements.
      stitched_linear.tif             Stitched mosaic image (TIFF).
      tile_positions_manual.json      Per-tile affine transforms.
    videos/                42 of 84 tiles (top 50% by per-tile median
                           total_snr).  Each TIFF is 2x spatially
                           downsampled (352x320 instead of 704x640),
                           8-bit, capped at 600 frames.  ~1.1 GB.
  README.md, CODE_CONTEXT.md  Project + codebase orientation.

  Tiles with videos included (sorted):
    2, 3, 4, 5, 9, 10, 11, 12, 13, 16, 17, 18, 19, 20, 21, 22, 23, 25,
    26, 28, 30, 34, 35, 36, 37, 38, 40, 43, 44, 45, 47, 48, 50, 52, 53,
    54, 55, 64, 65, 66, 67, 72


Requirements (cross-platform: macOS, Linux, Windows):
  - Python 3.9 or newer.
  - Either conda/mamba or Python's built-in `venv`.
  - No C compiler, no Cython, no system libraries to install separately.


Setup A — conda (recommended if you have conda or mamba):

  conda create -n yolk-sac python=3.11 -y
  conda activate yolk-sac
  pip install ./PerTileFlow


Setup B — pip + venv (no conda needed):

  python -m venv .venv

  # Activate (one of these, depending on OS / shell):
  source .venv/bin/activate                # macOS / Linux
  .\.venv\Scripts\Activate.ps1             # Windows PowerShell
  .\.venv\Scripts\activate.bat             # Windows cmd.exe

  python -m pip install --upgrade pip
  python -m pip install ./PerTileFlow

Either setup pulls napari + every runtime dependency automatically.
No separate `pip install napari[pyqt5]` step needed.


Launch (works on every OS the same way):

  python -m pertile.viewer.mosaic_readonly_app --config emb1/config.json


Useful CLI flags:
  --initial-field PI     Color edges by PI on startup (default: mean_Q).
                         Other options: phase, amp_Q, snr_pulse, snr_f0,
                         RPSI, eta, radius, length, quality_tier, f0_hz,
                         v_max.
  --min-quality A        Show only tier-A edges (default: B).  Use 'X'
                         to show every edge regardless of quality.


What you'll see:
  - napari window with the stitched mosaic in the background and the
    vessel network overlaid as colored line segments.
  - Right-side panel:
      * Color edges by any measured field (incl. Total SNR, Frequency,
        per-harmonic Magnitude / Phase / Resolution).
      * Tile filter: restrict measured-Q fields to a single tile.
      * Click an edge to inspect it — metadata appears in the panel.
      * "Plot Q(t) for selected" → popup with flow-rate waveform(s).
      * "Load video for selected tile" → for the 42 included tiles only.
        Other tile entries in the Browse tiles dropdown are greyed out
        with "(no video)".

  Visual overlay (click-to-play): works fine, sits at the right mosaic
  footprint (viewer auto-detects the downsample factor).

  The "Run optical flow on selected" button is HIDDEN in this build
  because the absolute-Q math is fragile under spatial downsampling.
  Visual analysis (Plot Q(t), harmonic SNR panel, BC simulation,
  per-tile inference) all use the analyzed graph directly and are
  unaffected.


Troubleshooting:

  - `ModuleNotFoundError: No module named 'PyQt5'` at viewer launch:
        pip install --force-reinstall pyqt5

  - Black napari window with no mosaic backdrop:
      The TIFF didn't load.  Verify
        emb1/analyzed/stitched_linear.tif is ~45 MB
      (a 0-byte file means a partial unzip).

  - Linux: `platform plugin 'xcb' could not be loaded` at startup:
      On Ubuntu / Debian:
        sudo apt install libxcb-xinerama0 libxcb-cursor0

  - Slow first launch (~30 s):
      That's the harmonic-class precompute.  Watch the terminal for
      the progress line.  Subsequent launches load instantly from
      the cache written back to the gpickle.
