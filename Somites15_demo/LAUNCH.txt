Quick-launch — Somites15 demo bundle
=====================================

Requirements:  Python 3.9+   (macOS / Linux / Windows)

Setup (one-time):
   1. cd into this folder
   2. pip install ./PerTileFlow
      (or in a fresh venv:  python -m venv .venv && source .venv/bin/activate)

Launch the read-only viewer:
   python -m pertile.viewer.mosaic_readonly_app --config emb1/config.json --rotate-cw

The `--rotate-cw` flag rotates the mosaic 90° clockwise on startup, which
puts the 15-somite embryo body axis vertical (matching the 21- and
27-somite demos).  Omit the flag if you'd rather see it as stored on disk.

What's in this bundle:
   emb1/analyzed/mosaic_graph_analyzed.gpickle   4,795-edge vessel graph
   emb1/analyzed/stitched_linear.tif             whole-organ mosaic
   emb1/analyzed/tile_positions_manual.json     per-tile registration
   emb1/videos/*.tif                             5 tile recordings (tiles 3, 4, 5, 13, 14)

Stage-15 (~25 hr) chick yolk-sac vasculature.  Heart rate ≈ 1 Hz with
measurable drift across the recording.  Click 'a' on a vessel to see
the new SNR_harm and SNR_ac diagnostics in the analysis panel.

Canonical reference vessels (tile 4):
   25013 — 41507   arterial (dorsal aorta)
    7135 — 59737   venous   (vitelline vein)
   36168 — 36179   venous   (secondary, used in figures)
